# مراجعة وتركيز BabiesPicks على العروض وMCP

21 أكتوبر 2026 — النطاق محلي في فرع codex/babiespicks-simplification.

طلب المالك: مراجعة جميع الصفحات وإزالة ما لا يخدم العروض وMCP أو يعرض خدمة غير جاهزة.

| الجزء | النتيجة | دليل التحقق |
|---|---|---|
| الرئيسية والبحث | عروض OFFER المنشورة وأسعار المنتجات الحديثة ذات روابط شراء صالحة؛ البحث في نفس الصفحة | اختبار نشر العرض وظهوره وسحبه، واختبارات حجب المسودات والروابط غير الصالحة |
| تفاصيل المنتج | اسم ومعلومات المنتج وأسعاره وروابط المتاجر؛ أزيلت الدرجات والتوصيات والأزرار غير الفعالة | اختبار الروابط الفعلي وواجهة الجوال |
| الكوبونات | متاجر من البيانات الفعلية فقط، صلاحية زمنية، نسخ كود، حالات خطأ صريحة | اختبار الكوبونات الحقيقي وحالة المعاينة الفارغة |
| الصفحات خارج النطاق | أزيلت صفحات الأدوات والحاسبة والاختبار والمقارنة والأفضل والتصنيفات والمراجعات والأدلة والبحث المنفصل | تحويلات 307 إلى العروض؛ الأسئلة والتواصل إلى عن الموقع |
| الصفحات الداعمة | عن الموقع والخصوصية والشروط وإفصاح العمولة فقط؛ لا وعود برسائل أو تقييمات أو تجارب | فحص العربية والإنجليزية والروابط وخريطة الموقع |
| MCP | إدارة موثقة مستقلة؛ بقيت صلاحيات النشر والإصدارات ومنع تكرار العمليات | 20 أداة عبر tools/list في الخدمة المحلية؛ اختبارات HTTP وOAuth وقاعدة البيانات |

## الأدلة

- نجح 96 اختبارًا في 18 ملفًا مع PostgreSQL اختبارية مستقلة، دون اختبارات متخطاة.
- نجحت 35 خطوة قبول فعلية، تشمل نشر العرض وظهوره وسحبه وروابط الشراء وحالات المسودة/الأرشفة والكوبونات والتحويلات.
- اجتازت الأنواع وESLint والبناء. تحققت المعاينة المحدثة عبر المتصفح من 31 مسارًا، دون أخطاء ترجمة أو أخطاء console.
- عرض 375 و1440 بكسل دون تمرير أفقي. قائمة الجوال تحتوي العروض والكوبونات فقط.
- المراجعة المستقلة قرأت مسارات العرض والنشر والكوبونات. عُولجت ملاحظتها عن روابط الشراء غير الصالحة باختبار RED→GREEN؛ لا ملاحظات مهمة متبقية ضمن نطاقها.
- أحدث سعر غير صالح لا يعيد سعرًا أقدم؛ تطبق واجهة الأسعار نفس قاعدة اعتماد وجهة المتجر المستخدمة في رابط الشراء.
- قاعدة المعاينة بقيت فارغة: 48 جدول تطبيق، صفر سجل. حُذفت قاعدة الاختبار وحاوية QA بعد التحقق.

## الحدود

المعاينة محدثة محليًا على المنفذ3316، وخدمة MCP المحلية على3317. لم يحدث commit أو push أو نشر خارجي. لم تُنقل بيانات الإنتاج ولم يُختبر اتصال ChatGPT خارجي. النشر المحلي عبر MCP ما زال معطلًا افتراضيًا حتى إعداد اتصال OAuth وصلاحية المالك. لا توجد عروض حقيقية مضافة حاليًا. بقيت المخططات والترحيلات التاريخية لحماية البيانات المستقبلية، دون تشغيل الخدمات القديمة.

السياسة sol61-all-v1. التنفيذ مباشر ومراجع واحد GPT-6.1 Sol بجهد medium. بدأ تسجيل القياس متأخرًا ولم تتوفر خطوط أساس كاملة لكل المشاركين؛ استهلاك المهمة والوفر غير معلومين. لا ادعاء بتوفير الحصة.
