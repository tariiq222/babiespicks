## العدّ والقراءة الكاملة عبر MCP

bp_get_publication_progress يقبل date اختياريًا بصيغة YYYY-MM-DD؛ الافتراضي يوم Asia/Riyadh الحالي. firstPublishedToday يعدّ أول publishedAt لكل منتج فريد، بما فيه ما أُرشف لاحقًا. dailyMinimum=3 وdailyMaximum=6 وremainingToMinimum وremainingCapacity توضح وضع اليوم. publishedTotal وdrafts أرقام وصفية، لا أهداف. لا حقول هدف شهري أو شرط استكمال مراجعات الشهر.

العداد خمس قراءات count دون أجسام المنتجات أو تاريخ الأسعار أو كتابة أو إبطال كاش. ليس قفل حصة ذريًا؛ التزام الكاتب الواحد وإعادة القراءة يمنعان تداخل الدفعات، وصلاحية النشر تأتي من الخادم.

إذا قُطع bp_get_product، استخدم bp_get_product_section للمصادر أو الحكم أو ترجمة محددة. اجمع chunk حتى nextOffset=null مع expectedVersion وexpectedHash من الجزء الأول. offsets وtotalCharacters بوحدات Unicode code points؛ البصمة SHA256 للنص JSON كاملًا بترميز UTF-8. قارن البصمة واحفظ النص الحالي كاملًا قبل التعديل؛ تغير النسخة أو البصمة يوجب إعادة القراءة. لا تستبدل نصًا أو مصادر مقطوعة، وأرسل الحقول المستهدفة فقط. الأداة قراءة فقط، ولا تغيّر bp_get_product القائم.

## الحفظ والتنسيق

احفظ صورًا حقيقية ووصفًا مفيدًا بالعربية والإنجليزية ومصادر صحيحة. استخدم expectedVersion وidempotencyKey ثابتًا. تعديل المنشور يحتاج صلاحية المالك وallowPublishedEdit ويظهر للعامة فورًا. عند نجاح الحفظ وفشل الكاش استعمل bp_revalidate فقط. تحقق من قراءة MCP وصفحتي AR/EN والتقييم والمصادر؛ لا نقرات إحالة تجريبية أو مشتريات.

المسار السعودي الحالي يتحقق من الصفحة ويحفظ سعر SAR الحقيقي عبر MCP ولا يشترط API أمازون جديدًا. الملاحظات الدولية غير المدعومة تؤجل بسياقها الحقيقي دون تحويل العملة أو إعادة تسميتها. لا اختلاق توصيل أو اعتماد مصدر أو كوبون.

احفظ سجل يوم مختصرًا وفهرس هوية بلا أسرار. تقرير مفيد في المجموعة القائمة يذكر النشر الجديد مقابل 3–6، روابطه والتقييمات والمصادر ومنع التكرار وأسباب النقص. لا حلقات استلام بين البوتين، ولا إيقاظ فرق البرمجة. الحصة المنتهية تُبلّغ مرة واحدة دون تكرار؛ عطل عابر له محاولة محدودة واحدة.
