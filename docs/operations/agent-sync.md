## السطح الحاكم الحالي: Rakazo

حدّد المالك الفريق القائم في Rakazo وMCP محورًا للقراءة والكتابة، وهدف 50 منتجًا جديدًا مكتملًا شهريًا مع بحث وتقييم من مواقع متعددة. الإشارات التاريخية أدناه إلى مشروع ChatGPT غير متحقق ليست وصفًا لهذا الفريق الحالي.

قُرئت إعدادات الناشر والمحدّث وروتينيهما والمجموعة عبر واجهة Rakazo الأصلية وحُفظت نسخ خاصة قبل تعديلها. طُبقت تعليمات 2026-11-03.2 وأعيدت قراءتها؛ النص مطابق بعد إزالة فراغ النهاية التي تطبقها المنصة. لم تتغير النماذج أو المزوّدات أو الاعتمادات أو الأذونات أو الأدوات المسندة، ولم يُنشأ بوت أو روتين آخر.

- الناشر: نفس روتينه، 10:00 يوميًا عند وجود نقص في النشر أو التقييمات. النص والجدول مقروءان؛ يتوقف تفعيله حتى نشر أداة تقدم MCP والتحقق منها. عند اكتمال الهدف والإسناد يغيّر نفس الروتين إلى أول كل شهر، ثم يعيده يوميًا عند نقص الشهر الجديد.
- محدّث الأسعار: نفس 06:00 و18:00 في Asia/Riyadh، وnotify=false كما كان؛ لا تعديل محتوى أو تقييم أو نشر منتجات.
- المجموعة: نفس العضوين، واسمها يوضح هدف 50. تقاريرها القديمة محفوظة كتاريخ وليست مرجعًا للجدول الحالي.
- أداة التقدم: قراءة خفيفة فقط؛ لا مصدر أسعار جديد أو صلاحية نشر أو تغيير لعقد SAR القديم.

فحص MCP قبل التغيير أثبت 55 أول نشر في نوفمبر، منها 18 بتقييم تحريري منشور؛ ومرجعين مصنفين للتقييم من hostين مختلفين صراحةً لمنتج واحد. هذا مؤشر إسناد لا حكم بأن البقية لم تُبحث. لذلك يستكمل عمل نوفمبر بحث وتقييم الموجود، دون إضافة منتجات تلقائيًا فوق الهدف.

معرّفات الحسابات ونسخ الإعدادات وبصمات النصوص والجداول الفعلية تحفظ في دليل خاص خارج Git. أول دفعة فعلية بالتعليمات الجديدة لا تثبت بمجرد حفظ النص أو اختبار العداد؛ تقاس بنتيجة MCP والمصادر والصفحات عند تشغيلها. لم يُشغّل اختبار استدلال مدفوع أو تُغيّر مهام فرق البرمجة. المرجع: [rakazo-team.md](rakazo-team.md).
